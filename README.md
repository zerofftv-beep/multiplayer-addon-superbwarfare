# Superb Warfare Multiplayer Vehicles Addon

Аддон, позволяющий нескольким игрокам садиться в технику Superb Warfare.

## Особенности
- Настраиваемое количество пассажиров (через конфиг)
- Работает с наземной и воздушной техникой

## Конфиг
`config/sbwaddon-common.toml`

```toml
maxPassengers = 4
```
